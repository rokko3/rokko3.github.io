<section class="routine-section" id="rutinas" aria-labelledby="routines-title">
  <div class="routine-heading">
    <p class="eyebrow">Rutinas por día</p>
    <h1 id="routines-title">Rutinas de entrenamiento</h1>
    <p>Elige el grupo muscular y sigue la sesión que corresponda a tu día. Ajusta el peso para mantener una técnica sólida en cada serie.</p>
  </div>

  <div class="routine-group" id="rutina-empuje">
    <div class="routine-group-title">
      <span class="project-number">01 / Empuje</span>
      <h2>Empuje</h2>
    </div>
    <div class="routine-grid">
      <article class="routine-card routine-card-lime" id="rutina-empuje-1">
        <div class="routine-card-top">
          <span class="project-number">Día 1 / Empuje</span>
          <span class="routine-duration">60 min</span>
        </div>
        <h3>Base de fuerza</h3>
        <ul class="exercise-list">
          <li>Press de banca · 4 x 6-8</li>
          <li>Press militar · 3 x 8-10</li>
          <li>Press inclinado · 3 x 8-10</li>
          <li>Extensión de tríceps · 3 x 10-12</li>
        </ul>
        <p class="routine-note">Descansa 90-120 segundos entre series principales.</p>
      </article>
      <article class="routine-card routine-card-coral" id="rutina-empuje-2">
        <div class="routine-card-top">
          <span class="project-number">Día 2 / Empuje</span>
          <span class="routine-duration">50 min</span>
        </div>
        <h3>Volumen y control</h3>
        <ul class="exercise-list">
          <li>Press con mancuernas · 4 x 8-10</li>
          <li>Elevaciones laterales · 4 x 12-15</li>
          <li>Fondos asistidos · 3 x 8-12</li>
          <li>Tríceps en polea · 3 x 12-15</li>
        </ul>
        <p class="routine-note">Prioriza un recorrido completo y sin rebotes.</p>
      </article>
    </div>
  </div>

  <div class="routine-group" id="rutina-tiron">
    <div class="routine-group-title">
      <span class="project-number">02 / Tirón</span>
      <h2>Tirón</h2>
    </div>
    <div class="routine-grid">
      <article class="routine-card routine-card-blue" id="rutina-tiron-1">
        <div class="routine-card-top">
          <span class="project-number">Día 1 / Tirón</span>
          <span class="routine-duration">60 min</span>
        </div>
        <h3>Tracción pesada</h3>
        <ul class="exercise-list">
          <li>Dominadas o jalón · 4 x 6-8</li>
          <li>Remo con barra · 4 x 8-10</li>
          <li>Face pull · 3 x 12-15</li>
          <li>Curl con barra · 3 x 10-12</li>
        </ul>
        <p class="routine-note">Inicia cada tirón desde la espalda, no desde las manos.</p>
      </article>
      <article class="routine-card routine-card-lime" id="rutina-tiron-2">
        <div class="routine-card-top">
          <span class="project-number">Día 2 / Tirón</span>
          <span class="routine-duration">50 min</span>
        </div>
        <h3>Espalda completa</h3>
        <ul class="exercise-list">
          <li>Jalón neutro · 3 x 10-12</li>
          <li>Remo sentado · 3 x 10-12</li>
          <li>Pájaros con mancuernas · 3 x 12-15</li>
          <li>Curl martillo · 3 x 10-12</li>
        </ul>
        <p class="routine-note">Mantén los hombros lejos de las orejas durante el movimiento.</p>
      </article>
    </div>
  </div>

        <ul class="exercise-list">

          <li>Prensa · 3 x 10-12</li>
          <li>Zancadas · 3 x 10 por pierna</li>
          <li>Gemelos de pie · 4 x 12-15</li>

        <ul class="exercise-list">

          <li>Hip thrust · 4 x 8-12</li>
          <li>Curl femoral · 3 x 10-12</li>
          <li>Gemelos sentado · 3 x 15-20</li>
        </ul>
        <p class="routine-note">Mueve la cadera hacia atrás y conserva la espalda neutra.</p>
